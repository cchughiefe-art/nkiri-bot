# TheNkiri Native App — Build 1

This build is the first integrated native-app milestone.

## Included

- Native Android project (Kotlin + Jetpack Compose)
- Search UI
- Movie and series detail flow
- Seasons and episodes
- Quality selection
- Android DownloadManager
- GitHub Actions APK build
- Node app API
- Render deployment configuration
- 30-second MovieX timeout patch via installer
- API syntax check workflow

## Deliberately not tested on the Android phone yet

The development strategy is build-first because the phone has limited resources.
