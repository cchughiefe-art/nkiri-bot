# TheNkiri Native App — Build 3

Build 3 completes the local Android UX layer.

- Home tabs for Latest, Movies, Series and K-Drama
- Recent searches stored locally
- Favorites / watchlist stored locally
- Download history stored locally
- Native Android Downloads shortcut
- Configurable API base URL
- API online/offline status
- Retry-friendly API client
- Updates channel button
- Telegram bot button
- Share TheNkiri button
- VLC Play Store button
- Local privacy explanation
- Back navigation
- Dark native UI polish
- Provider badges for TheNkiri / MovieX
