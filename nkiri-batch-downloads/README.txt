TheNkiri Batch Downloads

Adds Full Season Links (up to 30 episodes), Select Episodes, batch link generation,
and chunked Telegram result buttons. Existing device onboarding, channel verification,
daily share requirement, analytics, and .env are preserved.

Install from ~/nkiri-bot:
unzip -o nkiri-batch-downloads.zip
bash nkiri-batch-downloads/apply-batch-downloads.sh
